# 收货标签生成器 · 官方更新

此仓库仅提供程序下载和版本说明，不存放供应商业务数据、Excel、SSCC 记录或个人配置。源码仓库另行私有管理。

## 下载

进入 [最新稳定版](https://github.com/YUDIDIFEI/label-generator-releases/releases/latest)。

- 新供应商：下载 `label-generator-版本号-windows-x64.zip`，解压后运行“成品标签生成器.exe”。这是无业务数据的分发版，请放入自己的 `OrdertoShipment.xlsx` 并配置本供应商正确的 GS1 标识。
- 已有用户：不要用空白完整版覆盖原文件夹。v1.5.6 及更早版本先下载 `label-generator-1.6.0-update.zip`，解压后在旧软件“系统 → 维护模式 → 安装离线升级包”中选择含 `release-manifest.json` 的目录。
- v1.6.0 及后续版本：在“系统 → 维护模式 → 在线更新”中检查、下载，然后确认重启安装。

## 数据保护

更新前请完成当前作业并关闭 Excel/WPS。升级只替换程序，保留 Excel、SSCC 编码池、事务、历史及配置；安装前自动备份。新版本启动检查失败时仅回滚程序，不回退业务数据。

供应商无需 GitHub 账号。在线更新通过内置公钥验证版本说明和程序包完整性；网络不可用时可继续使用离线升级。运行环境变更会提示采用完整新版人工迁移，不自动覆盖数据。

不要把同一供应商的编码池复制到两台电脑同时使用。不要在 Issue 中上传业务数据、编码池、备份或密钥。

## 发布文件

- `*-windows-x64.zip`：Windows 64 位空白便携程序。
- `*-update.zip`：在线/离线通用程序升级包。
- `update.json`：软件读取的已签名稳定版说明。
- `SHA256SUMS.txt`：下载完整性校验。
- `使用说明.md`：首次接入与后续更新步骤。

在线更新签名不等同于 Windows EXE 商业代码签名。本程序暂未添加后者。
